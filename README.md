# Galaxy — 3D Satellite View

A lightweight, interactive 3D space visualization built with Three.js.

## Features

- 🌍 Detailed 3D Earth-style target body
- 🛰️ Animated satellite with solar panels and signal beacon
- 🪐 Multiple orbital paths
- ✨ 7,000+ background stars
- 🎛️ Orbit speed control
- 📡 Top-down camera mode
- 🏷️ Toggle satellite telemetry label
- 🖱️ Drag to rotate, scroll to zoom, double-click to reset
- 📱 Responsive HUD for desktop and mobile

## Run

Open `index.html` in a modern browser. The Three.js modules are loaded from jsDelivr, so an internet connection is required.

## Tech

- HTML5 / CSS3
- JavaScript (ES Modules)
- Three.js
